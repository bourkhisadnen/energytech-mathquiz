Interactive worksheet

The same questions as a self-marking PDF: one radio button per answer, a live score, and a mastery table by objective. Overleaf compiles it in your browser — press Recompile there, then download the PDF. Open the PDF in Adobe Acrobat Reader; the marking is form JavaScript, which Chrome's own viewer does not run.

The answer key is inside the file. It has to be, for the PDF to mark itself — anyone who opens the worksheet in a text editor can read it. Do not give this file to trainees before they have sat the paper.
